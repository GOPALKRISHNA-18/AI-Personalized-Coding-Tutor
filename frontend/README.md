# AI Personalized Coding Tutor - Frontend

A responsive and modern React 18 application built with Vite, Monaco Editor, Lucide Icons, and Recharts.

---

## Directory Structure
```
frontend/
├── src/
│   ├── components/      # Reusable UI components (Layout, MonacoEditor, etc.)
│   ├── pages/           # Application views (Dashboard, CodeEditor, Chat, etc.)
│   ├── services/        # API service modules
│   ├── styles/          # Global styles and theme definitions
│   └── utils/           # Helper functions and formatters
├── index.html
├── package.json
└── vite.config.js
```

---

## Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
